হ্যাঁ। এবার আমি তোমার জন্য এটাকে **একটা complete research roadmap** হিসেবে ধরছি। তবে আগে একটা গুরুত্বপূর্ণ update: সেপ্টেম্বর ২০২৬-এর current literature দেখে বোঝা যাচ্ছে HLS QoR prediction এখন active area। ForgeHLS নিজেই QoR prediction ও automated pragma exploration দিয়েছে; 2026-এ DiffHLS differential QoR prediction এবং MailoHLS Pareto-driven pragma optimization-এর মতো কাজও এসেছে। তাই আমাদের paper-এর novelty **“ML দিয়ে QoR predict করা”** হবে না। ([arXiv][1])

আমাদের strongest, manageable thesis direction হবে:

> **Uncertainty-Aware Multi-Objective HLS QoR Prediction Under Kernel-Level Distribution Shift**

---

# 1. পুরো thesis এক লাইনে কী?

তুমি একটি HLS design/configuration দেখে predict করবে:

$$
\hat y =
[\widehat{Latency},
\widehat{LUT},
\widehat{DSP},
\widehat{FF},
\widehat{BRAM}]
$$

কিন্তু শুধু prediction নয়।

তুমি আরও বলবে:

$$
u(x)=\text{prediction uncertainty}
$$

অর্থাৎ:

> **“এই prediction কতটা বিশ্বাসযোগ্য?”**

এবং model-কে এমন kernel-এ test করবে যেটা training-এ **কখনো দেখেনি**।

---

# 2. Existing work কী?

এটা বুঝতে না পারলে novelty ভুলভাবে claim করবে।

## Existing Work A — ForgeHLS

ForgeHLS হলো বড়-scale HLS dataset। Original paper 400K+ designs এবং 846 kernels report করেছে; data automated pragma insertion এবং extensive design-space exploration থেকে এসেছে। তারা QoR prediction ও automated pragma exploration-কে downstream tasks হিসেবে দেখিয়েছে। ([arXiv][1])

তোমার downloaded release-এর actual JSON artifact-এ আমরা **184,717 records / 471 algorithm names / 491 source+algorithm groups** পেয়েছি। Paper-এ final numbers লেখার সময় downloaded release/version-এর exact observed counts ব্যবহার করব।

### ForgeHLS আমাদের কী দিচ্ছে?

```text
C/C++ source
+
HLS configurations/pragmas
+
synthesis-derived QoR
```

যেমন:

```text
Worst-caseLatency
LUT
DSP
FF
BRAM_18K
```

Dataset documentation-এ design-level synthesis results এবং source/configuration information-এর কথা আছে। ([Hugging Face][2])

---

## Existing Work B — ML-based HLS QoR prediction

আগেও ML দিয়ে HLS QoR prediction হয়েছে। তাই শুধু:

```text
Random Forest
XGBoost
MLP
```

চালিয়ে QoR predict করে “novel method” বলা যাবে না।

Q-PIR-ও Random Forest/GP family-এর limitation এবং uncertainty ব্যবহার করে Pareto-front discovery-এর দিকে গেছে; তাদের method Quantile Regression Forest-এর prediction intervals ব্যবহার করে। ([ScienceDirect][3])

---

## Existing Work C — recent advanced prediction

2026-এর DiffHLS kernel-design pair ব্যবহার করে differential learning করেছে, GNN দিয়ে representation এবং pretrained code-LLM embeddings ব্যবহার করেছে; ForgeHLS-এ scalabilityও দেখিয়েছে। ([ResearchGate][4])

এটার implication:

> **শুধু “better predictor” বানানো খুব সহজ novelty claim হবে না।**

---

## Existing Work D — recent Pareto/optimization work

MailoHLS 2026-এ LLM + GNN + PEFT ব্যবহার করে Pareto-driven pragma optimization করেছে, seen ও unseen kernels দুটোতেই evaluation করেছে। ([arXiv][5])

HLS-Seek 2026-এ proxy reward model এবং uncertainty-aware MC dropout দিয়ে low-confidence candidates selectively synthesize করার ধারণা দিয়েছে। ([arXiv][6])

তাই:

> **“আমরা uncertainty ব্যবহার করেছি” একা novel claim-ও হবে না।**

আমাদের contribution-এর combination এবং exact experimental question গুরুত্বপূর্ণ।

# 4. Thesis-এর মূল hypothesis

আমরা চারটি hypothesis রাখব।

### H1 — Random split is optimistic

একই logical kernel-এর configuration variants random split-এ train/test দুইদিকে গেলে performance inflated হতে পারে।

### H2 — Kernel-disjoint split is harder

একেবারে নতুন logical kernel এ গেলে error বাড়বে।

### H3 — Uncertainty is informative

যেসব sample-এ uncertainty বেশি, সেখানে actual QoR errorও বেশি হওয়ার tendency থাকবে।

### H4 — Selective prediction helps

Uncertain samples reject/abstain করলে accepted predictions-এর error কমতে পারে।

এগুলো **results আগে থেকে assume করা নয়**। Experiment এগুলো support বা reject করবে।

# 17. Uncertainty module

এখানেই main novelty শুরু।

## Method A — Quantile Regression Forest

Random Forest-এর quantiles থেকে:

```text
lower quantile
median
upper quantile
```

উদাহরণ:

```text
Predicted LUT = 5000
90% PI = [4600, 5550]
```

Q-PIR HLS context-এ quantile regression forest এবং prediction intervals ব্যবহার করেছে, তাই literature baseline হিসেবে এটি relevant। ([ScienceDirect][3])


এটাই epistemic-style uncertainty signal হিসেবে ব্যবহার করা যায়।

# 19. Uncertainty কীভাবে validate করব?

শুধু uncertainty score দেখালে হবে না।

আমরা check করব:

$$
u(x) \uparrow \Rightarrow |y-\hat y| \uparrow ?
$$

Metrics:

```text
Spearman correlation
Pearson correlation
error by uncertainty quantile
```

Example:

```text
Lowest uncertainty 20%
→ MAE = ?

Highest uncertainty 20%
→ MAE = ?
```

যদি clear separation হয়, সেটা strong evidence।

---

# 20. Calibration

ধরো model 90% prediction interval দিয়েছে।

আমরা check করব:

$$
P(y \in PI_{90}) \approx 0.90
$$

আরও:

```text
50% interval
70%
80%
90%
95%
```

এর empirical coverage বের করব।

Figure:

```text
x = nominal coverage
y = observed coverage
```

Ideal diagonal থাকবে।

---

# 21. Prediction interval width

Coverage একাই যথেষ্ট নয়।

ধরো:

# 23. HLS interpretation

```text

        ↓

        ↓
```
